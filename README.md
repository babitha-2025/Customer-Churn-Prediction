# 📊 Customer Churn Prediction

A machine learning project that predicts whether a customer is likely to churn based on customer demographics, services, contract details, and billing information.

The project uses **Logistic Regression** with a complete preprocessing pipeline and provides an interactive **Streamlit web application** for real-time predictions.

---

## 🚀 Project Overview

Customer churn is an important business problem for subscription-based companies.

This project analyzes customer information and predicts the probability of churn. Businesses can use such predictions to identify high-risk customers and take appropriate retention actions.

### 🎯 Objective

The main objective is to:

- Predict whether a customer will churn
- Estimate the probability of customer churn
- Identify high-risk customers
- Provide an easy-to-use prediction interface
- Demonstrate an end-to-end machine learning workflow
